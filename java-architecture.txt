JVM (Java Virtual Machine)
The JVM is a component of Java that executes Java bytecode and provides a platform-independent runtime environment for Java applications.

Characteristics:
✅ Executes Java bytecode
✅ Provides platform independence
✅ Manages memory allocation and garbage collection
✅ Loads and executes Java classes
✅ Provides runtime services for Java applications

JRE (Java Runtime Environment)
The JRE is a software package that provides the runtime environment required to execute Java applications.

Characteristics:
✅ Provides the runtime environment for Java applications
✅ Contains the JVM
✅ Contains Java class libraries
✅ Supports execution of Java applications
✅ Does not provide development tools

JDK (Java Development Kit)
The JDK is a software package that provides the tools and libraries required to develop, compile, and execute Java applications.

Characteristics:
✅ Provides tools for Java development
✅ Contains the JRE
✅ Contains the JVM
✅ Provides the Java compiler (javac)
✅ Supports development, compilation, and execution of Java applications

Java Bytecode
Java Bytecode is an intermediate code generated by the Java compiler that is executed by the JVM.

Characteristics:
✅ Generated by the Java compiler
✅ Stored in .class files
✅ Is platform independent
✅ Executed by the JVM
✅ Enables the Write Once, Run Anywhere principle

Java Compiler (javac)
The Java Compiler (javac) is a tool that converts Java source code into Java bytecode.

Characteristics:
✅ Converts .java files into .class files
✅ Generates Java bytecode
✅ Detects compilation errors
✅ Is provided by the JDK
✅ Supports Java application development

Class Loader
A Class Loader is a JVM component that loads Java classes into memory during application execution.

Characteristics:
✅ Loads classes dynamically at runtime
✅ Loads classes into JVM memory
✅ Supports class loading on demand
✅ Follows parent delegation mechanism
✅ Is a part of the JVM

Garbage Collector
A Garbage Collector is a JVM component that identifies and removes unreachable objects from heap memory.

Characteristics:
✅ Reclaims unused memory
✅ Removes unreachable objects
✅ Runs automatically by the JVM
✅ Improves memory utilization
✅ Reduces manual memory management

Memory Areas of JVM
JVM Memory Areas are runtime memory regions used by the JVM to store and manage application data during execution.

Characteristics:
✅ Managed by the JVM
✅ Store objects, classes, and execution data
✅ Include Heap, Stack, Method Area, PC Register, and Native Method Stack
✅ Support application execution
✅ Provide memory management services

Relationship Between JVM, JRE, and JDK
Definition

JDK, JRE, and JVM are Java platform components that work together to develop and execute Java applications.

Characteristics:
✅ JDK contains JRE
✅ JRE contains JVM
✅ JVM executes Java bytecode
✅ JRE provides the runtime environment
✅ JDK provides development tools
